# 五笔 86 资料来源登记表

> 状态：Phase 0 初步调研。此表记录候选参考资料，不代表已获准复制其内容或将其数据直接纳入项目。

## 1. 选源原则

1. 版本明确：必须能确认是五笔字型 86 版。
2. 可追溯：有作者/发布方、版本信息和稳定链接。
3. 适合对应任务：规则教材、字根图、输入法码表的用途不同，不互相替代。
4. 许可明确：公开可访问不等于允许复制、改编或再发布。
5. 双源核对：正式数据至少需要一个主参考来源；关键编码/拆字数据还应使用独立来源交叉核验。
6. 差异可解释：不同输入法的词库、扩展字符、简码和候选策略可能不同，不能直接视为同一套标准数据。

## 2. 候选来源

### S001 — 清华大学出版社《五笔字型学用查词典（经典畅销版）》

- 作者：李宛新
- 出版社：清华大学出版社
- 版次：2014 年 7 月第 1 版
- ISBN：978-7-302-36599-0
- 在线资料：[出版社 PDF](https://www.tup.tsinghua.edu.cn/upload/books/yz/056601-01.pdf)
- 适用范围：86/98 版本区分、字根键盘图、键名字、字根拆分、编码和简码的人工查证。
- 优点：出版信息明确；使用说明明确说明 86 与 98 分别列示；目录列有 86 版字根键盘图、键名汉字表等。
- 限制：同一本书包含 86 和 98 两个版本，查阅时必须确认使用的是 86 栏；出版社版权内容不可因 PDF 可访问而批量复制或重新发布。
- 项目用途：**规则与示例的主要人工参考资料**。仅记录必要事实、核验结论和页码定位，不复制整表或大段说明。
- 状态：`reference_only`。

### S002 — 清华大学出版社《五笔字型输入法的方法和原则》章节 PDF

- 在线资料：[出版社 PDF](https://www.tup.tsinghua.edu.cn/upload/books/yz/051824-01.pdf)
- 适用范围：键名字、成字字根、单字取码、识别码及拆分原则的规则核对。
- 已核对内容：章节区分键名字、成字字根和普通字根；描述键名字连续击键、成字字根输入方式，以及不足四个字根时识别码的处理。
- 限制：规则章节不等于完整 86 版数据表；需结合版本明确的键位图和逐字资料核对。
- 项目用途：**规则说明的辅助来源**。
- 状态：`reference_only`。

### S003 — Rime 官方五笔方案仓库

- 仓库：[rime/rime-wubi](https://github.com/rime/rime-wubi)

- 限制：输入法方案码表可能受词库、扩展字符和实现策略影响；码表来源还涉及 ibus-table 的上游来源和授权。不能仅凭仓库公开就把数据复制到本项目。
- 项目用途：与出版资料逐条交叉核对；在确认上游数据许可、具体文件内容及分发义务前，不导入其码表。
- 状态：`candidate_cross_check`。

### S004 — riku-ri/wubi-kb 字根键盘图项目

- 状态：`reference_only`。

- 状态：`reference_only`。

## 3. 当前选源结论

| 数据类别 | 主参考 | 交叉核验 | 当前决策 |
| --- | --- | --- | --- |
| 键位与字根 | S001 的 86 版键盘图/附录 | S003、S004 | 逐键核验后录入；不复制图像 |
| 键名字根 | S001、S002 | S003 | 核对键位与类别后录入 |
| 成字字根 | S001、S002 | S003 | 逐项核验输入规则和笔画编码 |
| 汉字拆分 | S001 对应 86 栏 | S003 | 逐字核对；保留来源定位 |
| 简码/全码 | S001 对应 86 栏 | S003 | 分开记录编码类型，不混用 |
| 教学规则 | S002 | S001 | 结合 86 版规则校对并编写自己的教学表述 |

**目前不批准从任何单一在线码表批量导入完整字根或汉字编码。** 下一步先完成键位与字根清单的逐项核对，再决定是否建立可分发的数据集。

## 4. 版权与再分发边界

- 事实性规则可以通过独立核验后用自己的语言解释；不得复制教材大段原文、整页图表或受版权保护的版式。
- 采用开源码表前，必须记录仓库 commit、许可证、上游来源、数据文件路径和适用义务。
- 字体、图像、码表、程序代码的许可可能不同，必须分别确认。
- 若许可义务不适合本项目，改用独立人工核验的数据录入方式。
- 每条记录保留 source ID 和定位信息，以便内部审计；内部引用记录不等于获得再分发授权。
