# 汉字拆分样本审计

## 目的与边界

本文件记录可定位到来源的汉字拆分样本，供后续双源核验和数据模型验证使用。它不是正式教学数据，也不代表已建立完整编码表。

- 只采用明确标注为 86 版的内容。
- 保留来源原始转录；不要静默修正 OCR 或大小写。
- 单一来源的样本一律为 `needs_review`，不能进入 `data/verified/`。
- 版权保护资料仅记录必要的短事实、定位信息和审计结论，不复制整页或成批表格。
- 拆分字形不等同于已经建立可引用的 Root ID；Root ID 映射须单独核验。

## 新增候选来源

**S010 —《五笔字型速学速查词典》**

- 作者：李宛新
- 出版社：清华大学出版社
- 版次：2018 年 1 月第 1 版
- ISBN：978-7-302-48952-8
- PDF：[出版社原文](https://www.tup.com.cn/upload/books/yz/074387-01.pdf)
- 使用说明明确：正文表格分别列出 86 版和 98 版的字根及编码；示例说明第一行为 86 版，第二行为 98 版。
- 附录 E 为 86 版字根键盘图，附录 F 为 98 版字根键盘图。
- 版权状态：仅人工查阅；未获得批量复制或再分发授权。

### 样本解释

出版社 PDF 的示例说明明确将“朗”的第一行定义为 86 版，并给出拆分字形“丶彐厶月”及编码显示“YVCe”。本项目保留原始大小写，不在审计阶段擅自把 `e` 改为 `E`。当前仅能确认该书对自身版本行的标注，尚未完成第二来源交叉验证，也未将各拆分部件映射到已核验的字根实体。

## 本轮结论

- S010 具备明确的 86/98 版本分栏说明，比只标注“86版”的一般在线查询页更适合做人工核对。
- PDF 文本层可检索，但部分正文表格 OCR 会把双版本行、列和特殊字形混在一起；不能据此批量自动导入。
- “朗”仅作为格式/定位样本，状态为 `needs_review`；不创建 `character-code` JSON 记录。
- 下一步应从正文挑选少量高频汉字，逐条确认 86 版第一行，并与另一份明确标注 86 版且来源独立的材料比对；对 OCR 有歧义的条目必须回看原页图像。
