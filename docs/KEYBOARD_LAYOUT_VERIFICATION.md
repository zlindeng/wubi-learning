# 86 版键盘布局核验记录

> 核验范围：五区、25 个正式字根键、区位号和键名字。  
> 状态：布局骨架已交叉核验；**不代表各键上的完整字根清单已核验**。

## 1. 核验结论

## 2. 来源与交叉核验

- **S001 清华大学出版社《五笔字型学用查词典（经典畅销版）》**：目录明确将附录 E 标为“86版五笔字型字根键盘图”（书内页码 411），附录 F 则为 98 版图（页码 412）。这为版本边界提供了明确定位。出版社 PDF：<https://www.tup.tsinghua.edu.cn/upload/books/yz/056601-01.pdf>
- **S003 Rime 官方五笔方案**：仓库提供明确命名为 86 的方案文件，可作为输入法实现的交叉核验候选；码表上游许可尚未确认，因此本记录不复制其码表。<https://github.com/rime/rime-wubi>
- **独立公开教学资料**：多个明确标注 86 版的资料给出的五区键序和键名序一致。示例：<https://www.zp0719.com/wubi-table/>、<https://wubi.sdcb.ai/roots>。这些网页仅作为交叉检查线索，不作为完整字根表的授权或唯一权威来源。

## 3. 证据强度与边界

已确认：
- 五个区的首笔类别及每区五个键的顺序。
- 25 个键对应的区位号。
- 每个键的键名字根。
- Z 不属于 25 个普通字根键。

本记录**没有确认**：
- 每个键上所有基本字根、变体和部件的完整集合。
- 哪些部件应独立建模为字根，哪些只是字根的变形或拆分说明。
- 每个字根的准确字形、笔画、结构与拆分适用范围。
- 键名字根与成字字根的完整名单。

上述未确认内容不得由本表推导，也不得据此生成正式练习题。

## 4. 后续核验步骤

1. 从 S001 的 86 版附录 E 逐键记录字根候选及页码定位，不保存或复制整张教材图。
2. 使用第二个独立来源逐项核对；对不一致项建立差异记录。
3. 区分基本字根、键名字根、成字字根、字根变形和仅用于口诀的描述。
4. 在数据授权边界明确前，只保存自行核验的必要事实及出处定位，不批量复制第三方码表。
5. 通过人工复核后，才将具体字根写入 `data/verified/`。
