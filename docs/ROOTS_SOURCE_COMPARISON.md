# 86 版字根候选资料差异核对（第二轮）

> 本文只比较公开资料明确展示的候选形体，不判定完整字根全集。所有条目均为 `needs_review`，不能进入正式课程数据。

## 1. 本轮采用的来源

- S001：清华大学出版社《五笔字型学用查词典》，附录 E 标注为 86 版字根键盘图（书内页码 411）。目前 PDF 文本层能确认附录名称和页码，但截图接口未能成功取得该页图像，因此尚未完成原图逐项辨读。<https://www.tup.tsinghua.edu.cn/upload/books/yz/056601-01.pdf>
- S006：0564bbs 的 86 版键盘图与常见字根展示。<https://www.0564bbs.cn/wubi/roots/>
- S007：Benber 86 版入门字根图，明确说明只列常用形体、不保证穷尽。<https://wubi.benber.net/guide/roots>
- S009：葡萄枝导航 86 版常用字根、一级简码和键位练习。<https://www.ptz123.com/wubi-table>
- S008：千千秀字，主要用于口诀和概念交叉核对，不作为完整字根列表。<https://www.qqxiuzi.cn/zh/wubi.htm>

这些网页之间是否存在共同上游资料尚未证明，不能简单视为相互独立的权威来源。

- 表中内容是各页面的展示摘要，不代表来源完整性。

- S007 页面存在重复形体以展示形态/口诀的情况，不能按文本出现次数统计 Root 数量。

## 3. 对上一版候选表的更正

上一版 `ROOTS_CANDIDATE_AUDIT.md` 将若干候选项合并列在同一栏，容易让人误以为整行都来自 S006。实际上各网站展示范围并不相同，且有些行是多个来源的混合摘要。

**更正：上一版表格不应作为来源逐项归属依据。** 后续逐条审计应使用本文件的来源分栏，或直接记录来源页面和定位。旧表保留为早期探索记录，但不得作为事实清单引用。

## 4. 下一步核验顺序

1. 获取 S001 附录 E 可辨读图像，逐键确认键帽上的字根。
2. 将每个图形分别标为 `root`、`variant`、`descriptor` 或 `mnemonic_only`。
3. 对非 Unicode 形体建立自绘 SVG 或笔画描述，不以私用区字符或相似汉字替代。
4. 用 S001 正文 86 栏的具体汉字拆分，核对每个候选形体是否实际作为一个字根出现。
5. 再与一个来源明确、许可可接受的独立数据源交叉核验。
6. 每条记录保留原始页面定位、核验人、核验日期、冲突说明和状态。
