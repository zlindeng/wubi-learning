# 产品需求文档（PRD）

## 1. 产品概述

### 1.1 产品定位

面向完全零基础成年人的五笔 86 版互动学习网站。产品通过短课程、可视化键盘、拆字演示和即时练习，帮助用户从认识键位逐步过渡到独立输入汉字。

### 1.2 核心原则

- **互动优先**：把知识拆成小任务，用户通过选择、敲键和拆字来学习。
- **渐进教学**：一次引入少量新概念，先理解再练习，再混合复习。
- **即时反馈**：指出正确与错误，并解释原因，而不只显示对错。
- **可解释**：展示字根、拆分过程、取码步骤和数据来源。
- **可持续复习**：记录学习状态、错题和薄弱知识点。
- **低负担**：界面清晰，减少无关动画、复杂游戏化和鼠标往返。

## 2. 目标用户与场景

### 2.1 目标用户

- 成年人，完全没有五笔基础。
- 可能熟悉拼音输入，但不了解五笔字根、键位和编码规则。
- 希望通过短时、持续的练习掌握五笔，而不是阅读大段理论。

### 2.2 典型场景

1. 初次进入网站，了解五笔输入的基本原理。
2. 通过键盘图认识五区和各键位字根。
3. 学习一组字根，立即进行识别与回忆练习。
4. 观察一个汉字如何按规则拆分并得到编码。
5. 完成编码练习，查看错误原因。
6. 返回错题和薄弱知识点进行复习。

## 3. MVP 范围

### 3.1 必须交付（P0）

| 模块 | 需求 |
| --- | --- |
| 学习首页 | 展示学习进度、当前课程、继续学习入口和复习建议 |
| 五笔键盘 | 展示标准 QWERTY 键盘、五区分布、键位与字根详情 |
| 字根课程 | 字根卡片、所属键位/区、口诀或助记、说明与例字 |
| 字根练习 | 看字根找键、看键找字根、口诀找键、混合测验 |
| 拆字教学 | 展示汉字结构、逐步拆分、取码过程和解释 |
| 基础编码 | 支持物理键盘输入、进度、退格、重试、跳过、显示答案 |
| 键名字根 | 独立讲解并练习，规则内容须经数据核验 |
| 成字字根 | 独立讲解并练习，规则内容须经数据核验 |
| 一级简码 | 讲解并练习一级简码，明确其与全码的区别 |
| 错题本 | 保存题目、用户答案、正确答案、错误次数和最近错误时间 |
| 学习报告 | 学习时长、课程完成、练习数、正确率和模块掌握情况 |
| 本地持久化 | 刷新后恢复进度；支持学习数据导入和导出 |

### 3.2 暂不纳入 MVP

- 用户注册、登录和云端同步
- 排行榜、好友、社交和公开挑战
- 视频课程和直播
- AI 自动推断或生成正式五笔编码
- 其他五笔版本（如 98、新世纪）
- 完整词组、文章输入和专业级打字测速（后续迭代）

## 4. 信息架构与页面

| 路由 | 页面 | 主要内容 |
| --- | --- | --- |
| / | 学习首页 | 学习概览、继续学习、复习入口 |
| /lessons | 课程学习 | 课程目录、课程内容和课程练习 |
| /practice | 专项练习 | 字根、拆字、编码等练习入口 |
| /mistakes | 错题复习 | 错题列表、筛选和重新练习 |
| /statistics | 学习报告 | 学习趋势、正确率和知识点掌握情况 |

桌面端采用左侧导航与主内容区布局；需要时提供右侧辅助信息。移动端响应式适配，但核心输入练习优先保证桌面物理键盘体验。

## 5. 学习路径

### 阶段一：认识五笔

- 五笔输入的基本原理
- 86 版键盘布局
- 横、竖、撇、捺、折五个区的概念

### 阶段二：学习字根

- 按区学习各键位字根
- 结合键位图、字根卡片和助记信息
- 每区练习后进行混合测试

### 阶段三：理解汉字拆分

- 汉字结构与字根概念
- 书写顺序与拆分原则
- 逐步拆分示例
- 拆分过程与取码结果的对应关系

具体拆分规则及其优先级必须以经过核验的 86 版资料为准，不允许教学文案自行简化成可能误导的口诀。

### 阶段四：掌握基础编码

- 键名字根
- 成字字根
- 一般汉字取码
- 末笔字型识别码
- 一级简码
- 后续扩展二级、三级简码与四码全码

教学时必须区分简码输入与完整编码，说明何时需要补充识别码或末码。

### 阶段五：扩展输入（后续）

- 二级、三级简码
- 双字词、三字词、四字词和多字词
- 高频词练习

### 阶段六：综合训练（后续）

- 单字、词组和文章输入
- 速度与准确率训练
- 根据错题强化薄弱知识点

## 6. 关键交互要求

### 6.1 键盘与字根

- 键盘图突出当前教学区域或目标键位。
- 点击键位可查看该键上的字根、助记与例字。
- 练习题尽量支持物理键盘作答，也提供必要的点击操作。
- 每次答题后即时反馈，错误时展示正确答案和简短解释。

### 6.2 拆字教学

- 将拆分过程分步骤呈现，避免一次性展示最终答案。
- 每一步说明选择的字根及其依据。
- 最终展示取码序列，并说明简码/全码类型。
- 只展示有来源、有校验记录的拆字示例。

### 6.3 编码练习

- 显示目标汉字和预期输入长度/进度。
- 支持退格、重试、跳过和查看答案。
- 正误反馈应区分输入错误、编码知识错误和操作问题。
- 不应依赖操作系统输入法输出汉字来判定五笔按键序列。

### 6.4 错题与复习

至少记录：
- 题目 ID 和题型
- 用户作答
- 正确答案
- 错误次数
- 最近一次错误时间
- 所属课程/知识点

复习后更新答题记录，不应因重复练习而丢失历史表现。

## 7. 学习状态与通过标准

课程状态：

- `not_started`：未开始
- `learning`：学习中
- `review`：需要巩固
- `mastered`：已掌握

初始建议：课程练习正确率达到 90% 可标记为掌握；低于标准则进入巩固状态。阈值必须集中配置，避免散落在多个组件中。未来可按课程难度调整。

## 8. 数据与隐私

- MVP 不要求用户注册。
- 学习记录保存在浏览器 IndexedDB。
- 提供导出备份和导入恢复能力。
- 明确提示清除浏览器站点数据可能导致本地学习记录丢失。
- 不在没有明确产品需求和用户授权的情况下上传学习记录。

## 9. MVP 验收标准

- 新用户可以从首页进入第一课并完成基础学习路径。
- 用户可以查看键位与字根，并完成字根识别练习。
- 用户可以逐步查看已核验汉字的拆分和取码过程。
- 用户可以用物理键盘完成基础编码练习，获得即时反馈。
- 错题被记录，并可重新练习。
- 课程状态、学习记录在刷新后仍然存在。
- 用户可以导出并重新导入学习数据。
- 核心领域规则有单元测试；关键用户路径有端到端测试。
- 未经核验的数据不会进入正式课程和练习。
