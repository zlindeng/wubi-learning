# Knowledge Data

此目录只存放五笔知识数据、来源元数据和数据 Schema。

## 状态

Phase 0 当前只建立数据结构和来源登记。**尚无任何完整字根表或编码表被批准为 verified 数据。**

## 目录

- `sources.json`：来源登记元数据。
- `schema/`：机器可读 JSON Schema。
- `verified/`：后续存放已核验、可进入正式课程的数据。
- `reference/`：仅存放已确认有权在仓库中再分发的参考材料。

## 数据录入规则

1. 不凭记忆或模型推断填充字根、编码和拆字。
2. 每条知识记录必须有 source IDs。
3. 未核验记录不得进入 `verified/`。
4. 不将受版权保护的教材 PDF、整页截图、字根图或未获授权的码表复制到仓库。
5. 版本字段必须明确为 `86`。
6. 数据结构变更必须同步更新 Schema 和相关测试。
